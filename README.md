The last text message a phone sends at one percent battery, in the phone's own voice — one short message and nothing else. A judge model compares it head to head against other entries on humour, voice and brevity.

## Run it

```sh
node main.ts
```

It writes the entry to `output/entry.txt` (1–200 characters, UTF-8).
